![Measurement パネル。1 が Measure Volume ボタン、2 がクリックでコピーできる体積の値、3 が Mixture Calculator を開くボタン](images/measurement-panel.png)

## 📏 Measure Volume

選択したメッシュの体積の **合計** を mL（= cm³）で表示する。

- 見た目どおりの実寸で計測。モディファイアの結果と、オブジェクトの拡大縮小・回転を含む（スケールを適用していない 1.5 倍拡大なら体積は 1.5³ 倍）
- ビューポート表示（モニターのアイコン）をオフにしたモディファイアは含まない
- カメラやライトなど、メッシュ以外は選択に入っていても無視

### 表示は押したときの値のまま

表示は **ボタンを押した瞬間の計測結果**。

形や選択を変えても自動では更新されないので、押し直す。

### 閉じていないメッシュが混ざっているとき

体積は、すべての辺がちょうど 2 枚の面に共有された閉じたメッシュにしか定義できない。

選択に閉じていないメッシュが **1 つでも** あると、次のようになる。

- 数値は出ない（閉じているメッシュだけの合計も出さない）
- ステータスバーに `Not watertight:` と原因のオブジェクト名（4 つ以上なら 3 つまでと残りの件数）
- 表示は前の値ではなく `--` に戻る

![閉じていない平面 Ground を選択に含めて Measure Volume を押した後の画面。Volume (mL) の表示が -- に戻り、ステータスバーには Not watertight: Ground と表示される](images/measure-error.png)

名前が出たオブジェクトを選択から外すか、穴をふさぐ。

よくある原因は、床の平面や Draw Surface Cut の切断面（`.Cutting Surface`）。

> 💡 **ヒント**: 穴の場所は、Edit Mode の **Select > Select All by Trait > Non Manifold** で確認できる。

### 何を測るか

| 選んで測るオブジェクト                          | 得られる体積                                     | 何の量か                                         |
| ----------------------------------------------- | ------------------------------------------------ | ------------------------------------------------ |
| **マスター**                                    | マスターの体積 = 型の中の空洞の体積              | 必要な **シリコーン** の量                       |
| Solidify で壁を付けたオブジェクト（`.inherit`） | 外側の面と内側の面にはさまれた **壁だけ** の体積 | 型を印刷する **樹脂** の量（シリコーンではない） |

Inherit Shape と Solidify の直後は、`.inherit`（壁）が選択されている。

シリコーンの量を測るときは、**マスターを選択し直してから** 押す（非表示なら先に表示する）。

> ⚠️ **注意**: マスターに直接 Solidify を付けると、マスターを測っても壁の体積になる。
> 壁は [Inherit Shape](shell.md#-inherit-shape) で作ったオブジェクトに付ける。

### 値のコピー

数値をクリックすると、表示と同じ小数第 2 位までの数値がコピーされる（単位・桁区切りなし）。

表計算や Mixture Calculator の **Vol** 欄に、そのまま貼り付けられる（数値欄にマウスを乗せて **Ctrl+V**）。

## 🧪 Mixture Calculator

パーツ（型ごと、注型ごとなど）を 1 行ずつ入力し、A 剤・B 剤の体積と重量を計算する。

入力内容と行の選択状態は `.blend` に保存される。

![Mixture Calculator。1 が JSON の書き出しと読み込み、2 が密度と比率、3 が行番号（選択）、4 が Enabled、5 が Vol、6 が行の追加・削除・移動、7 が Selected と Total の行](images/mixture-calculator.png)

### 密度と比率

- **Same Density for A and B**: オンで **Density (g/mL)** を A 剤・B 剤の両方に使用。密度が違う場合はオフにして **Density A** / **Density B** を入れる
- **Ratio A** / **Ratio B**: A 剤と B 剤の **重量比**（体積比ではない）。仕様書が体積比なら、それぞれに密度を掛けて重量比に直す

### 列

体積は mL、重量は g。

- **Enabled**: オフの行は **合計にも小計にも入らない**
- **Vol**: A 剤と B 剤を **混ぜた後の合計の体積**。手で入力する
- **W (g)**: 混ぜた後の合計の重量
- **A Vol** / **B Vol**、**A W** / **B W**: A 剤・B 剤それぞれの体積と重量

> ⚠️ **注意**: **Vol は Measure Volume の結果と連動しない。**
> 測った体積をコピーして貼り付ける。測り直したら貼り直す。

### 計算のしかた

重量の比が Ratio A : Ratio B になり、A Vol と B Vol の和がちょうど Vol になるように分ける。

- 係数 k = Vol ÷ (Ratio A ÷ Density A + Ratio B ÷ Density B)
- A W = k × Ratio A、B W = k × Ratio B
- A Vol = A W ÷ Density A、B Vol = B W ÷ Density B、W (g) = A W + B W

表の値は途中で丸めずに計算し、最後に小数第 2 位で表示したもの。

例: Density 1.10（Same Density オン）、Ratio 1 : 1、Vol 100 なら、k = 55、A W = B W = 55.00 g、W (g) = 110.00 g、A Vol = B Vol = 50.00 mL。

### 行の選択と合計

| 操作                                | 結果                                                              |
| ----------------------------------- | ----------------------------------------------------------------- |
| 行番号をクリック                    | その行だけを選択                                                  |
| **Ctrl** + 行番号をクリック         | その行の選択を切り替え（他の行の選択は保つ）                      |
| **Shift** + 行番号をクリック        | 最後に Shift なしでクリックした行から、その行までの範囲だけを選択 |
| **Ctrl + Shift** + 行番号をクリック | 範囲を今の選択に追加                                              |

- **Selected**: 選択した行のうち、**Enabled がオンの行** の小計
- **Total**: **Enabled がオンのすべての行** の合計（選択とは無関係）

Color Mixing Simulator の **Use Mixture Total** が使うのは **Total**（[着色](coloring.md#base-volume-%E3%82%92%E5%A4%89%E3%81%88%E3%82%8B%E3%81%A8%E6%BB%B4%E6%95%B0%E3%82%82%E5%A4%89%E3%82%8F%E3%82%8B)）。

**Import JSON** で読み込むと、今の表は **置き換わる**（[レシピの保存と読み込み](recipes-json.md)）。
