# 計測と配合（Measurement）

[README に戻る](../README.md)

## 📝 TL;DR

- **Measure Volume** は、選んだメッシュの体積を実寸の mL で合計する
- 表示は **押したときの値のまま**。形を変えたら押し直す
- 閉じていないメッシュが 1 つでも混ざると、数値は出ずに **`--`** に戻る
- シリコーンの量は **マスター** を測る。壁を測ると樹脂の量になる
- **Mixture Calculator** の Ratio は **重量比**。Vol は手で入力する

## 🧭 パネルの中身

Measurement パネルでは、選択したメッシュの体積を測る（**Measure Volume**）。

その体積から、A 剤・B 剤それぞれの量を計算する（**Mixture Calculator**）。

![Measurement パネル。1 が Measure Volume ボタン、2 がクリックでコピーできる体積の値、3 が Mixture Calculator を開くボタン](images/measurement-panel.png)

## 📏 Measure Volume

1. 測りたいメッシュを選択する（複数可）。
2. **Measure Volume**（図の 1）を押す。
3. 選択したメッシュの体積の **合計** が、**Volume (mL)** の右（図の 2）に表示される。単位は mL（= cm³）。

### 測られる体積

見た目どおりの実寸で測る。

モディファイア（ビューポート表示がオンのもの）の結果と、オブジェクトの拡大縮小・回転を含む。

たとえば、スケールを適用していないオブジェクトを各辺 1.5 倍に拡大すると、体積は 1.5³ 倍になる。

- ビューポート表示（モディファイア一覧のモニターのアイコン）をオフにしたモディファイアは含まない。
- カメラやライトなど、メッシュ以外のオブジェクトは、選択に入っていても無視される。

### 表示は押したときの値のまま

表示される値は、**ボタンを押した瞬間の計測結果**。

その後にモデルを変形・拡大したり、選択を変えたりしても、表示は自動では変わらない。

形を変えたら、もう一度 **Measure Volume** を押して測り直す。

まだ一度も測っていないときは `--` と表示される。

### 閉じていないメッシュが混ざっているとき

体積は、すき間のない閉じたメッシュにしか定義できない。

閉じたメッシュとは、すべての辺がちょうど 2 枚の面に共有されているメッシュのこと。

選択の中に閉じていないメッシュが **1 つでも** あると、次のようになる。

- 数値は出ない。閉じているメッシュの分だけの合計も出さない。
- ステータスバーに `Not watertight:` に続けて、原因のオブジェクト名が表示される。4 つ以上ある場合は 3 つまで表示し、残りは件数で表示する。
- Volume (mL) の表示は、前の値ではなく `--` に戻る。前の値が残っていると、今の選択の体積と誤解するため。

![閉じていない平面 Ground を選択に含めて Measure Volume を押した後の画面。Volume (mL) の表示が -- に戻り、ステータスバーには Not watertight: Ground と表示される](images/measure-error.png)

対処は、名前が出たオブジェクトを選択から外すか、そのメッシュの穴をふさぐこと。

> 💡 **ヒント**: 穴の場所は、Edit Mode の **Select > Select All by Trait > Non Manifold** で確認できる。

よくある原因は、もともと閉じていない面。

床として置いた平面や、Draw Surface Cut で作った切断面（`.Cutting Surface`）などがこれに当たる。

### 何を測るか

どのオブジェクトを選んで測るかで、得られる体積の意味が変わる。

| 選んで測るオブジェクト                          | 得られる体積                                     | 何の量か                                         |
| ----------------------------------------------- | ------------------------------------------------ | ------------------------------------------------ |
| **マスター**                                    | マスターの体積 = 型の中の空洞の体積              | 必要な **シリコーン** の量                       |
| Solidify で壁を付けたオブジェクト（`.inherit`） | 外側の面と内側の面にはさまれた **壁だけ** の体積 | 型を印刷する **樹脂** の量（シリコーンではない） |

シリコーンが入るのは型の中の空洞で、その形はマスターと同じ。

壁のオブジェクトの体積は、空洞を含まない。

Inherit Shape と Solidify の直後は、`.inherit`（壁）が選択されている。

シリコーンの量を測るときは、**マスターをクリックして選択し直してから** Measure Volume を押す。

マスターを非表示にしている場合は、先に表示してから選択する。

> ⚠️ **注意**: マスターに直接 Solidify を付けると、マスターを測っても壁の体積になる。
> マスターはそのまま残し、[Inherit Shape](shell.md#-inherit-shape) で作ったオブジェクトに壁を付ける。

### 値をコピーする

表示された数値（図の 2）をクリックすると、その数値がクリップボードにコピーされる。

コピーされるのは、表示と同じ小数第 2 位までの数値だけ。単位や桁区切りは付かない。

表計算ソフトや、下の Mixture Calculator の **Vol** 欄にそのまま貼り付けられる。

> 💡 **ヒント**: Blender の数値欄には、マウスを乗せて **Ctrl+V** で貼り付けられる。

## 🧪 Mixture Calculator

**Mixture Calculator**（図の 3）を押すと、サイドバーの横に幅の広い計算表が開く。

パーツ（型ごと、注型ごとなど）を 1 行ずつ入力すると、それぞれに必要な A 剤・B 剤の体積と重量が計算される。

入力した内容と行の選択状態は、`.blend` に保存される。

![Mixture Calculator。1 が JSON の書き出しと読み込み、2 が密度と比率、3 が行番号（選択）、4 が Enabled、5 が Vol、6 が行の追加・削除・移動、7 が Selected と Total の行](images/mixture-calculator.png)

### 密度と比率を設定する（図の 2）

| 項目                         | 意味                                                                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Same Density for A and B** | オンのとき、**Density (g/mL)** の 1 つの値を A 剤・B 剤の両方に使う。A 剤と B 剤の密度（比重）が違う場合はオフにして、**Density A** と **Density B** を別々に入れる。 |
| **Ratio A** / **Ratio B**    | A 剤と B 剤の **重量比**。「100:10」なら 100 と 10、「10:1」なら 10 と 1 のように入れる（比が同じなら結果も同じ）。                                                   |

比率は、体積比ではなく **重量比** として扱う。

製品の仕様書に体積比しか書かれていない場合は、体積比のそれぞれに密度を掛けて、重量比に直してから入れる。

### 行を入力する

表の各列は次のとおり。体積は mL、重量は g。

| 列                    | 内容                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------- |
| **#**                 | 行番号。クリックで行を選択する（下の「行を選ぶ」）。                                   |
| **Enabled**           | オフにした行は計算表に残るが、**合計にも小計にも入らない**（計算値は薄く表示される）。 |
| **Name**              | パーツの名前。表の下の検索欄で名前による絞り込みができる。                             |
| **Vol**               | そのパーツに使う、A 剤と B 剤を **混ぜた後の合計の体積**（mL）。手で入力する。         |
| **W (g)**             | 混ぜた後の合計の重量                                                                   |
| **A Vol** / **B Vol** | A 剤・B 剤それぞれの体積                                                               |
| **A W** / **B W**     | A 剤・B 剤それぞれの重量（はかりで量る値）                                             |

> ⚠️ **注意**: **Vol は Measure Volume の結果と連動しない。**
> 測った体積をクリックしてコピーし、Vol 欄に貼り付ける。
> 測り直したときも、貼り付け直す必要がある。

### 計算のしかた

A 剤と B 剤は、次の 2 つを満たすように分けられる。

- A 剤と B 剤の重量の比が、Ratio A : Ratio B になる
- A Vol と B Vol の和が、ちょうど Vol になる

A 剤・B 剤の体積は、それぞれ「重量 ÷ 密度」。したがって、計算は次のとおり。

- 係数 k = Vol ÷ (Ratio A ÷ Density A + Ratio B ÷ Density B)
- A W = k × Ratio A、B W = k × Ratio B
- A Vol = A W ÷ Density A、B Vol = B W ÷ Density B、W (g) = A W + B W

表の値は、途中の k などを丸めずに計算し、最後に小数第 2 位で表示したもの。

手計算で確かめるときに途中で丸めると、最後の桁がずれることがある。

例: Same Density をオンにして、Density 1.10、Ratio 1 : 1、Vol 100 とする。

k = 100 ÷ (1/1.10 + 1/1.10) = 55。

したがって、A W = B W = 55.00 g、W (g) = 110.00 g、A Vol = B Vol = 50.00 mL になる。

### 行を選ぶ・合計を見る

| 操作                                | 結果                                                              |
| ----------------------------------- | ----------------------------------------------------------------- |
| 行番号をクリック                    | その行だけを選択                                                  |
| **Ctrl** + 行番号をクリック         | その行の選択を切り替え（他の行の選択は保つ）                      |
| **Shift** + 行番号をクリック        | 最後に Shift なしでクリックした行から、その行までの範囲だけを選択 |
| **Ctrl + Shift** + 行番号をクリック | 範囲を今の選択に追加                                              |

表の下には、次の行が表示される（図の 7）。

- **Selected**: 選択した行のうち、**Enabled がオンの行** の小計。行を 1 つも選んでいないときは表示されない。
- **Total**: **Enabled がオンのすべての行** の合計。選択とは関係ない。

選択した行があるときは、**−**（削除）と **▲ / ▼**（1 行ずつ上下に移動）が押せる。

**+** は、空の行を末尾に追加する（図の 6）。

### 着色に体積を渡す

Color Mixing Simulator の **Use Mixture Total** を押すと、ここの **Total** の体積がカラープロファイルの Base Volume に入る。

Selected の小計ではない。

詳しくは [着色](coloring.md#2-%E3%82%B7%E3%83%AA%E3%82%B3%E3%83%BC%E3%83%B3%E3%81%AE%E3%83%99%E3%83%BC%E3%82%B9%E3%82%92%E8%A8%AD%E5%AE%9A%E3%81%99%E3%82%8B) を参照。

### 保存と読み込み

図の 1 の **Export JSON** / **Import JSON** で、密度・比率とすべての行を JSON ファイルに保存・読み込みできる。

読み込むと、今の表は **置き換わる**。

詳しくは [レシピの保存と読み込み](recipes-json.md) を参照。
