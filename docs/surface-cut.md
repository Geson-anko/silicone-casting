# 型の分割（Surface Cut / Separate Loose Parts）

[README に戻る](../README.md)

型は 2 段階で割る。

1. **Surface Cut** で、切断面に沿って薄く削るモディファイアを付ける。形は割れて見えても **オブジェクトは 1 つのまま**。
2. **Separate Loose Parts** で、離れた塊を別々のオブジェクトにする。

![Surface Cut の欄。1 が Operand、2 が Thickness、3 が Add Surface Cut、4 が Boundary Extension、5 が Input、6 が Draw Surface Cut、7 が Edit Cutting Surface](images/surface-cut-panel.png)

## 🔪 Surface Cut モディファイア

切断面を法線に沿って **Thickness** だけ押し出した板を、型から引く（Difference）。

型には 1 つの **Surface Cut** モディファイアとして付く。

- 切断面のオブジェクトは参照されるだけ。後から編集すると切断もその場で更新
- 作った後も、モディファイアで **Cutting Surface**、**Thickness**、**Even Thickness**（既定オフ）、**Solver**（**Manifold** が既定、**Exact** も可）を変更可能

> ⚠️ **注意**: **Thickness** の既定値は最小値の 0.001 mm で、切断の幅はほぼ 0。
> すき間が必要なら、作る前か、作った後のモディファイアで設定する。

## 📎 Add Surface Cut

切断面のメッシュを自分で用意したときに使う。

割る型をアクティブにし、**Operand** に切断面のメッシュ（型とは別）を指定して押す。

押せる条件は [Boolean](shell.md#%E3%83%9C%E3%82%BF%E3%83%B3%E3%81%8C%E6%8A%BC%E3%81%9B%E3%81%AA%E3%81%84%E3%81%A8%E3%81%8D) と同じ。

> ⚠️ **注意**: この **Operand** は、Boolean の Operand と同じ設定。片方で変えると、もう片方も変わる。

## ✏️ Draw Surface Cut

アクティブな型の表面に閉じた線（ループ）を描くと、そのループを縁とする曲面の切断面が作られる。

- 描く対象は、描き始めた時点の見た目の形（モディファイア込み）
- 4 分割表示（Quad View）の 3D ビューや、Air Vents の描画中は開始できない
- **Boundary Extension**: 切断面を縁より外へ延ばし、型の表面を確実に突き抜けさせる。既定 0.1 mm、0 で延長なし。描画中の変更はプレビューに反映され、確定済みの切断面には影響しない
- **Input**: **Freehand** / **Vertex** / **Edge**。描画中も切り替え可能

### 描画の流れ

**Enter で確定できるのは、プレビューのときだけ**。

![Draw Surface Cut の流れの図。左ドラッグで描き、C でループを閉じ、Space でプレビューし、Enter で確定する。Backspace でプレビューから描画に戻り、Esc でいつでも取り消せる](images/draw-surface-cut-flow.png)

1. 型の表面を **左ドラッグ** して線を描く。マウスを離して視点を回し、線の末端の近くから続けられる。

2. 線を始点の近くまで戻したら、**C** でループを閉じる。

   > ⚠️ **注意**: 線を始点まで戻してマウスを離しただけでは、ループは閉じない。**C** を押して、はじめて閉じたループになる。

3. 中空の形などで内側のループが要るときは、同じように描いて **C** で閉じる。

4. **Space** でプレビューする。閉じていない線が残っていると進めない。

5. **Enter** で確定する。

![Draw Surface Cut の描画中の画面。赤枠のヘッダーに今使えるキーが表示され、型の表面に描きかけの線（オレンジ）が見える](images/draw-surface-cut.png)

### 描画中のキー

| キー                                               | 動作                                                                                                                       |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 左ドラッグ                                         | 線を描く（Freehand）。マウスが型から外れると線は止まり、末端の近くから再開できる。離れた場所へ飛んで続けることはできない。 |
| **Ctrl** + 左クリック                              | 線の末端からクリックした位置まで、画面上の直線を表面に投影した線を足す（Freehand）                                         |
| 左クリック                                         | Vertex: 近くの見えている頂点に合わせて線をつなぐ。Edge: 見えている辺を線につなぐ                                           |
| **Alt** + 左クリック                               | Edge: 四角面の辺のループをまとめて足す                                                                                     |
| **Ctrl** + 左クリック                              | Edge: 線の末端からクリックした辺まで、最短の辺の経路を足す                                                                 |
| **S**                                              | 描きかけの線（なければ最後に閉じたループ）を滑らかにする。押すほど滑らかになる。                                           |
| **C**                                              | 描きかけの線を閉じてループにする                                                                                           |
| **Space**                                          | 切断面をプレビューする                                                                                                     |
| **Enter**                                          | プレビュー中のとき、確定する                                                                                               |
| **Backspace**                                      | プレビュー中: 描画に戻る。描画中: 描きかけの線を消す。描きかけの線がなければ、最後に閉じたループを開き直す                 |
| **Ctrl+Z** / **Ctrl+Shift+Z**（または **Ctrl+Y**） | 描画中の取り消し / やり直し（macOS では Cmd も使える）                                                                     |
| **Esc**                                            | 取消。描いた線とプレビューをすべて捨てて終了する。型は何も変わらない。                                                     |

> ⚠️ **注意**: ヘッダーの表示は `Undo/Redo: Ctrl-Z/Shift-Z` だが、やり直しは **Ctrl+Shift+Z**。Shift+Z だけでは何も起きない。

視点の操作（中ボタン、ホイール、テンキー、ナビゲーションギズモ）と **N** / **T** は、描画中も使える。視点を変えても線は変わらない。

描けるのは、1 本の外側のループと、その内側の穴のループ。交差・接触するループや外側のループが 2 本あると、プレビューでエラーになる。

### 確定した後

- アクティブだった型に **Surface Cut** モディファイアが 1 つ付く
- 切断面は `<型の名前>.Cutting Surface` という別オブジェクトとして残り、モディファイアから参照される
- 型はまだ 1 つのオブジェクト。[Separate Loose Parts](#-separate-loose-parts) で分ける

![確定後の画面。1 が Outliner に残った切断面のオブジェクト Mold.Cutting Surface、2 が型に付いた Surface Cut モディファイアとその入力（Cutting Surface、Thickness、Even Thickness、Solver）](images/surface-cut-result.png)

> ⚠️ **注意**: 切断面は閉じていない面。全選択すると、Measure Volume はエラーになり、Export STL では STL に混ざる。

## 🪄 Edit Cutting Surface

描いた切断面の内側の曲がり方を、手で調整する。

Surface Cut を付けた型（または切断面）をアクティブにして押すと、切断面が Edit Mode で開き、**縁以外の内側の頂点だけ**（頂点グループ **Cut Interior**）が選択される。

頂点を動かすと、切断がその場で更新される。**Tab** で Object Mode に戻る。

![Edit Cutting Surface を押した後の Edit Mode。切断面の内側の頂点だけが選択されている](images/edit-cutting-surface.png)

## 🧩 Separate Loose Parts

選択中のメッシュを、離れた塊ごとに別のオブジェクトにする。

![Separate Loose Parts の前後の Outliner。元のオブジェクトは非表示で残り、塊ごとの新しいオブジェクトが同じコレクションにできる](images/separate-loose-parts.png)

- 元のオブジェクトの **すべてのモディファイアを適用したコピー** を、塊ごとに分割
- パーツは元と同じコレクションに入り、モディファイアは持たない。オブジェクトに割り当てたマテリアルは引き継ぐ
- 元のオブジェクトは削除されず、メッシュとモディファイアもそのまま。**非表示** になり、選択も外れる
- 押した後は **新しいパーツがすべて選択** され、最初のパーツがアクティブ

> ⚠️ **注意**: **ビューポート表示（モニターのアイコン）をオフにしたモディファイアも適用する**。画面で見えていない効果も焼き込まれる。

表示をオフにしたモディファイアの扱いは、機能ごとに違う。

| 機能                     | 表示をオフにしたモディファイア                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **Separate Loose Parts** | 表示のオン・オフに関係なく、**すべて適用する**                                                  |
| **Measure Volume**       | ビューポート表示がオフなら **含めない**                                                         |
| **Export STL**           | レンダー表示（カメラのアイコン）がオフなら **含めない**。ビューポート表示のオン・オフは関係ない |

やり直すときは、パーツを削除して、Outliner で元のオブジェクトを表示し直す。

> ⚠️ **注意**: このまま Export STL を押すと、全パーツが 1 つの STL に入る（[STL 出力](export-stl.md)）。
