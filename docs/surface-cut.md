# 型の分割（Surface Cut / Separate Loose Parts）

[README に戻る](../README.md)

## 📝 TL;DR

- 型を割る作業は **Surface Cut → Separate Loose Parts** の 2 段階です
- Surface Cut を付けただけでは、形が割れて見えても **オブジェクトは 1 つのまま** です
- Draw Surface Cut は **描く → C で閉じる → Space でプレビュー → Enter で確定** の順です。線を始点まで戻しただけでは **ループは閉じません**
- Thickness の既定値は 0.001 mm で、**切断の幅はほぼ 0** です。必要に応じて設定しましょう
- Separate Loose Parts は、**ビューポート表示をオフにしたものも含めて** すべてのモディファイアを適用します。元のオブジェクトは非表示で残ります

## 🧭 2 段階で割る

型を割る作業は 2 段階です。

1. **Surface Cut** で、型に「切断面に沿って薄く削る」モディファイアを付けます。この時点では、形は割れて見えても **オブジェクトは 1 つのまま** です。
2. **Separate Loose Parts** で、離れた塊をそれぞれ別のオブジェクトにします。

![Surface Cut の欄。1 が Operand、2 が Thickness、3 が Add Surface Cut、4 が Boundary Extension、5 が Input、6 が Draw Surface Cut、7 が Edit Cutting Surface](images/surface-cut-panel.png)

## 🔪 Surface Cut モディファイア

Surface Cut は、切断面のメッシュを法線に沿って **Thickness** の厚さだけ押し出して板にします。

そして、その板を型から引き（Difference）ます。

型には、1 つの **Surface Cut** モディファイアとして付きます。

- 切断面のオブジェクトは参照されるだけで、変更されません。切断面を後から編集すると、切断もその場で更新されます。
- 作った後でも、モディファイアの欄で **Cutting Surface**（切断面のオブジェクト）、**Thickness**、**Even Thickness**（既定はオフ）、**Solver**（**Manifold** が既定、**Exact** も選べる）を変えられます。

> ⚠️ **注意**: **Thickness** の既定値は、入力できる最小値の 0.001 mm です。切断の幅はほぼ 0 になります。
> すき間が必要なら、作る前に Thickness を設定するか、作った後にモディファイアの Thickness を変えましょう。

Surface Cut の付け方は 2 通りあります。

| 方法                 | 使うとき                                     |
| -------------------- | -------------------------------------------- |
| **Add Surface Cut**  | 切断面にするメッシュを自分で用意したとき     |
| **Draw Surface Cut** | 型の表面に線を描いて、切断面を作らせたいとき |

## 📎 Add Surface Cut

1. 割る型をクリックしてアクティブにします（選択された状態にします）。
2. 欄の一番上の **Operand**（図の 1）に、切断面にするメッシュを指定します。型とは別のメッシュでなければなりません。
3. **Thickness**（図の 2）を確認して、**Add Surface Cut**（図の 3）を押します。

ボタンが押せる条件は、[Boolean](shell.md#%E3%83%9C%E3%82%BF%E3%83%B3%E3%81%8C%E6%8A%BC%E3%81%9B%E3%81%AA%E3%81%84%E3%81%A8%E3%81%8D) と同じです。アクティブと Operand が同じだと押せません。

> ⚠️ **注意**: この **Operand** は、Boolean の欄の Operand と同じ設定です。片方で変えると、もう片方も変わります。

## ✏️ Draw Surface Cut

型の表面に閉じた線（ループ）を描きます。

すると、そのループを縁とする曲面の切断面が自動で作られます。

### 始める前に

- 割る型を **アクティブ** にします。線は、アクティブなメッシュの表面（モディファイアを含めた見た目の形）に描きます。形は、描き始めた時点のものが使われます。
- 3D ビューを 4 分割表示（Quad View）にしていると始められません。1 画面の 3D ビューで使いましょう。
- Air Vents の描画中は始められません。先に確定か取消をしてください。
- **Boundary Extension**（図の 4）: 作られる切断面を、描いた縁より外側へこの長さだけ延ばします。延ばすことで、切断面が型の表面を確実に突き抜けます。既定は 0.1 mm で、0 にすると延長しません。描画中も変更でき、プレビューに反映されます。すでに確定した切断面には影響しません。
- **Input**（図の 5）: 線の入れ方を **Freehand**（自由に描く）、**Vertex**（頂点をクリック）、**Edge**（辺をクリック）から選びます。描画中も切り替えられます。

**Draw Surface Cut**（図の 6）を押すと、描画が始まります。

3D ビューのヘッダーに、今使えるキーが表示されます。

### 描画の流れ

描画には「描く」「プレビュー」の 2 つの状態があります。

**Enter で確定できるのは、プレビューのときだけ** です。

![Draw Surface Cut の流れの図。左ドラッグで描き、C でループを閉じ、Space でプレビューし、Enter で確定する。Backspace でプレビューから描画に戻り、Esc でいつでも取り消せる](images/draw-surface-cut-flow.png)

1. 型の表面を **左ドラッグ** して線を描きます。途中でマウスを離して視点を回し、線の末端の近くから描き続けられます。

2. 線を始点の近くまで戻したら、**C** を押してループを閉じます。始点から離れていると閉じられません（ヘッダーに案内が出ます）。

   > ⚠️ **注意**: 線を始点まで戻してマウスを離しただけでは、ループは閉じません。**C** を押して、はじめて閉じたループになります。

3. 中空の形などで内側にもう 1 本ループが要るときは、同じように描いて **C** で閉じます。

4. **Space** を押すと、切断面が作られてプレビュー表示になります。閉じていない線が残っていると、プレビューに進めません。

5. プレビューを確認して **Enter** を押すと、確定します。

![Draw Surface Cut の描画中の画面。赤枠のヘッダーに今使えるキーが表示され、型の表面に描きかけの線（オレンジ）が見える](images/draw-surface-cut.png)

### 描画中のキー

| キー                                               | 動作                                                                                                                           |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 左ドラッグ                                         | 線を描く（Freehand）。マウスが型から外れると線は止まり、末端の近くから再開できます。離れた場所へ飛んで続けることはできません。 |
| **Ctrl** + 左クリック                              | 線の末端からクリックした位置まで、画面上の直線を表面に投影した線を足す（Freehand）                                             |
| 左クリック                                         | Vertex: 近くの見えている頂点に合わせて線をつなぐ。Edge: 見えている辺を線につなぐ                                               |
| **Alt** + 左クリック                               | Edge: 四角面の辺のループをまとめて足す                                                                                         |
| **Ctrl** + 左クリック                              | Edge: 線の末端からクリックした辺まで、最短の辺の経路を足す                                                                     |
| **S**                                              | 描きかけの線（なければ最後に閉じたループ）を滑らかにする。押すほど滑らかになります。                                           |
| **C**                                              | 描きかけの線を閉じてループにする                                                                                               |
| **Space**                                          | 切断面をプレビューする                                                                                                         |
| **Enter**                                          | プレビュー中のとき、確定する                                                                                                   |
| **Backspace**                                      | プレビュー中: 描画に戻る。描画中: 描きかけの線を消す。描きかけの線がなければ、最後に閉じたループを開き直す                     |
| **Ctrl+Z** / **Ctrl+Shift+Z**（または **Ctrl+Y**） | 描画中の取り消し / やり直し（macOS では Cmd も使えます）                                                                       |
| **Esc**                                            | 取消。描いた線とプレビューをすべて捨てて終了します。型は何も変わりません。                                                     |

> ⚠️ **注意**: ヘッダーには `Undo/Redo: Ctrl-Z/Shift-Z` と表示されます。
> ですが、やり直しは **Ctrl+Shift+Z**（Ctrl と Shift を押しながら Z）です。Shift+Z だけでは何も起きません。

視点の操作と、**N** / **T** によるサイドバー・ツールバーの開閉は、描画中もそのまま使えます。

視点の操作とは、中ボタンドラッグでの回転、ホイールでのズーム、テンキーの 1 / 3 / 7（Ctrl との組み合わせも可）、画面右上のナビゲーションギズモです。

視点を変えても、線は変わりません。

描けるのは、1 本の外側のループと、その内側の穴のループです。

投影して交差・接触するループや、外側のループが 2 本ある場合は、プレビューのときにエラーが表示されます。描き直しましょう。

### 確定した後

- アクティブだった型に、**Surface Cut** モディファイアが 1 つ付きます。
- 切断面は `<型の名前>.Cutting Surface` という別のオブジェクトとしてシーンに残り、モディファイアから参照されます。
- 型はまだ 1 つのオブジェクトです。続けて [Separate Loose Parts](#-separate-loose-parts) で分けましょう。

![確定後の画面。1 が Outliner に残った切断面のオブジェクト Mold.Cutting Surface、2 が型に付いた Surface Cut モディファイアとその入力（Cutting Surface、Thickness、Even Thickness、Solver）](images/surface-cut-result.png)

> ⚠️ **注意**: 切断面のオブジェクトは、閉じていない面です。
> 全選択して Measure Volume を押すと、この面でエラーになります。
> 全選択して Export STL を押すと、STL に混ざります。

## 🪄 Edit Cutting Surface

描いて作った切断面の、内側の曲がり方を手で調整します。

1. Surface Cut を付けた型（または切断面そのもの）をアクティブにします。
2. **Edit Cutting Surface**（図の 7）を押します。

切断面が Edit Mode で開き、**縁以外の内側の頂点だけ** が選択された状態になります。

内側は頂点グループ **Cut Interior** に、縁は **Cut Boundary** に入っています。

**G** などで頂点を動かすと、型の切断がその場で更新されます。

終わったら、**Tab** で Object Mode に戻りましょう。

![Edit Cutting Surface を押した後の Edit Mode。切断面の内側の頂点だけが選択されている](images/edit-cutting-surface.png)

## 🧩 Separate Loose Parts

選択中のメッシュを、離れた塊ごとに別のオブジェクトにします。

Processing パネルの中ほどにある、常に表示されたボタンです。

1. 割った型を選択します（複数可）。
2. **Separate Loose Parts** を押します。

![Separate Loose Parts の前後の Outliner。元のオブジェクトは非表示で残り、塊ごとの新しいオブジェクトが同じコレクションにできる](images/separate-loose-parts.png)

押すと、次のようになります。

- 元のオブジェクトの **すべてのモディファイアを適用したコピー** が作られ、塊ごとに別オブジェクトに分けられます。
- 新しいパーツは、元と同じコレクションに入ります。モディファイアは持ちません（形は焼き込み済み）。オブジェクトに割り当てたマテリアルも引き継ぎます。
- 元のオブジェクトは削除されません。メッシュとモディファイアもそのままで、**非表示** になり、選択も外れます。
- 押した後は、**新しくできたパーツがすべて選択** され、そのうち最初のパーツがアクティブになります。

> ⚠️ **注意**: Separate Loose Parts は、**ビューポート表示（モニターのアイコン）をオフにしたモディファイアも適用します**。
> 画面で見えていないモディファイアの効果も、パーツに焼き込まれます。

表示をオフにしたモディファイアの扱いは、機能ごとに違います。

| 機能                     | 表示をオフにしたモディファイア                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **Separate Loose Parts** | 表示のオン・オフに関係なく、**すべて適用する**                                                  |
| **Measure Volume**       | ビューポート表示がオフなら **含めない**                                                         |
| **Export STL**           | レンダー表示（カメラのアイコン）がオフなら **含めない**。ビューポート表示のオン・オフは関係ない |

やり直したいときは、パーツを削除します。そして、Outliner の目のアイコンで元のオブジェクトを表示し直しましょう。

> ⚠️ **注意**: このまま Export STL を押すと、全パーツが 1 つの STL に入ります。
> パーツごとの出力は、[STL 出力](export-stl.md) を見てください。
