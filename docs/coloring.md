# 着色（Coloring）

[README に戻る](../README.md)

## 📝 TL;DR

- 染料の種類と滴数から、仕上がりの **色と透明度** を予測できます
- 画面の **1〜4 の枠を上から順に** 入力していきます
- **Base Volume を変えると、すべての滴数が同じ倍率で変わります**。体積を先に決めましょう
- 計算に入るのは、**On がオンで、滴数が 0 より大きい染料** だけです
- **白を含めて、どの染料も透明度を下げます**

## 🎨 シミュレータを開く

Coloring パネルの **Color Mixing Simulator** を押すと、サイドバーの横に幅の広い混色シミュレータが開きます。

シリコーンに入れる染料の種類と滴数から、仕上がりの色と透明度を予測します。

色の組み合わせは、名前付きの **プロファイル** として保存できます。プロファイルは `.blend` に残ります。

シミュレータの中は、上から順に 1〜4 の番号付きの枠になっています。この順に入力していきましょう。

![Color Mixing Simulator の全体。1 がプロファイルの選択、2 がベースの設定、3 が染料の一覧と編集、4 が結果の色](images/color-simulator.png)

## 🛠️ 1〜4 の枠の使い方

### 1. プロファイルを選ぶ

**1. Choose a Named Profile** の枠で、配色のプロファイルを選びます。

最初は空なので、右の **+** を押してプロファイルを作ります。

名前はダブルクリックで変更できます。

**−** は、選択中のプロファイルを削除します。すでにオブジェクトに適用したマテリアルは、消えずに残ります。

### 2. シリコーンのベースを設定する

**2. Set the Silicone Base Color, Volume, and Transparency** の枠で、染料を入れる前のシリコーンを設定します。

| 項目                                       | 内容                                                                                                                                      |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Base Volume (mL)**                       | 染料を混ぜるシリコーンの体積                                                                                                              |
| **Use Mixture Total**                      | Mixture Calculator の **Total**（Enabled がオンの行の合計）を Base Volume に入れます。Total が 0 のときはエラーになり、何も変わりません。 |
| 色の欄                                     | 着色前のシリコーンの色（わずかな黄ばみなども含めて）                                                                                      |
| **Base Transparency (1 clear / 0 opaque)** | 着色前の透明度。1 が透明、0 が不透明                                                                                                      |

#### Base Volume を変えると滴数も変わる

Base Volume を変えると、そのプロファイルの **すべての染料の Actual Drops が同じ倍率で変わります**。

たとえば Base Volume を 200 から 300 にすると、どの染料の滴数も 1.5 倍になります。

濃度（体積あたりの滴数）は変わらないので、結果の色と透明度は変わりません。

Use Mixture Total で Base Volume が変わったときも同じです。

> 💡 **ヒント**: 「この体積に、この滴数を入れたらどうなるか」を見たいときは、**先に Base Volume を決めてから** Actual Drops を入れましょう。

### 3. 染料を入れる

**3. Add Colorants and Enter the Actual Drops** の枠で、使う染料を 1 行ずつ追加します。

**+** で行を追加し、**−** で選択中の行を削除します。

![染料の一覧。列の番号は 1 が On、2 が Color、3 が Dye、4 が Hue (degrees)、5 が Lightness (%)、6 が Calibration Drops / mL、7 が Actual Drops。青枠が行の追加・削除、オレンジ枠が選択中の染料の色を編集する欄](images/color-colorants.png)

| 列                           | 内容                                                                       |
| ---------------------------- | -------------------------------------------------------------------------- |
| 1 **On**                     | オフにした染料は計算に入りません（色にも透明度にも影響しません）。         |
| 2 **Color**                  | その染料の色                                                               |
| 3 **Dye**                    | 染料の名前                                                                 |
| 4 **Hue (degrees)**          | 色相（0〜360 度）                                                          |
| 5 **Lightness (%)**          | 明度。100% は白、0% は黒、その間は茶色のような暗めの色を表します。         |
| 6 **Calibration Drops / mL** | その染料が **Color の色に見える濃度**（ベース 1 mL あたりの滴数）          |
| 7 **Actual Drops**           | 実際に入れる滴数。つまようじで入れるような少量のために小数も入れられます。 |

#### 染料の色の入れ方

行を選ぶと、下に **Edit Selected Dye Color** の欄が開きます。

カラーピッカー、**Hex (sRGB)**、**Hue (degrees)**、**Lightness (%)** のどれからでも色を入れられます。

- 染料の色は **彩度 100% に固定** されます。ピッカーや Hex で彩度の低い色を選んでも、同じ色相・明度で彩度 100% の色に直されます。
- Hex は `#RRGGBB` の形で入れます。形式が正しくない入力は無視され、前の色が残ります。
- 白い染料は、Lightness を 100% にします。白は、他の色を淡くする染料として扱われます。
- 黒や茶色は、Lightness を低くして表します。

#### Calibration Drops / mL の決め方

同じ染料でも、濃く入れるほど色は濃くなり、シリコーンは不透明になります。

Calibration Drops / mL は、「Color で指定した色が、どの濃度のときの色か」を表す基準です。

既定値の 1.0 は目安にすぎません。実際の値は染料ごとに違います。

たとえば、試しにシリコーン 50 mL に 25 滴入れて、見えた色を Color に入れたとします。

このときの Calibration Drops / mL は、25 ÷ 50 = 0.5 ですね。

### 4. 結果を見る

**4. Check the Mixed Color (click values to copy)** の枠に、結果が常に表示されます。

![結果の枠。1 が Result Color の見本、2 がクリックでコピーできる Hex・sRGB 8-bit・Linear RGB の値、3 が Result Transparency、4 が Apply to Selected ボタン](images/color-result.png)

- 図の 1 **Result Color**: 混ぜた後の色の見本です。計算結果なので、直接は編集できません。
- 図の 2 **Hex (sRGB)** / **sRGB 8-bit** / **Linear RGB**: 結果の色の値です。クリックすると、その文字列がクリップボードにコピーされます。
- 図の 3 **Result Transparency**: 混ぜた後の透明度です（1 が透明、0 が不透明）。
- 図の 4 **Apply to Selected**: 結果の色のマテリアルを、選択中のメッシュに適用します（下を参照）。

## 🧮 色と透明度の決まり方

計算に入るのは、**On がオンで、Actual Drops が 0 より大きい染料** だけです。

それぞれの染料について、まず **濃度** を求めます。

- **濃度** = Actual Drops ÷ (Base Volume × Calibration Drops / mL)

濃度 1 は、「ちょうど Color の色になる濃さ」です。

- **色**: ベースの色と各染料の色の反射スペクトルを、濃度を重みにして混ぜ合わせます。絵の具のような減法混色の近似です。ベースの重みは「1 − 濃度の合計」です（0 未満にはなりません）。
- **透明度**: Result Transparency = Base Transparency × (1 − 濃度の合計) です。濃度の合計が 1 以上なら 0（不透明）になります。

> ⚠️ **注意**: **色に関係なく**、白を含めて、計算に入る染料はすべて透明度を下げます。

## 🖼 マテリアルに適用する

**Apply to Selected** は、Object Mode で選択中のメッシュにマテリアルを割り当てます。

マテリアルはプロファイルごとに 1 つで、名前は `Silicone Mix - <プロファイル名>` です。

- マテリアルの枠がないメッシュには、このマテリアルを追加します。
- すでにマテリアルがあるメッシュでは、アクティブなマテリアルの枠を、このマテリアルに置き換えます。

マテリアルの色と透過（Transmission）は、プロファイルを編集するとその場で更新されます。

## 💾 保存と読み込み

シミュレータの一番上の **Export JSON** / **Import JSON** で、すべてのプロファイルを JSON ファイルに保存したり、読み込んだりできます。

読み込んだプロファイルは、今のリストに **追加** されます。

詳しくは [レシピの保存と読み込み](recipes-json.md) を見てください。
