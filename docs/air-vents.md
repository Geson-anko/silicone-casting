# 空気孔（Air Vents）

[README に戻る](../README.md)

描いた線に沿った円い管を作り、**選択した型すべて** からくり抜く。

![Air Vents の欄。1 が Diameter、2 が Draw Air Vents ボタン](images/air-vents-panel.png)

- 対象は、**Draw Air Vents** を押した時点で選択されていたメッシュ（描画中に選択を変えても変わらない）
- **Diameter**: 管の直径（既定 2 mm）。描画中の変更はプレビューに反映される
- 4 分割表示（Quad View）の 3D ビューや、Draw Surface Cut の描画中は開始できない

## 📐 描画平面の決まり方

線は型の表面ではなく、**1 枚の平面の上** に描く。

- **最初のクリック** で選択した型の面をクリックすると、**その点を通り、その面と平行な平面** が描画平面になる。以後は変わらない
- 型のないところをクリックしても平面は決まらない
- 以後の点は、マウスから画面の奥へ伸ばした線と **平面の交点** に置かれる。曲面の上でも面に沿わず、型の外でも平面上に置かれる
- 平面を真横から見ているときや、平面が視点より後ろにあるときは、点が追加されない

管の断面の **中心は描画平面にちょうど乗る**（上にも下にもずれない）。

管は平面の両側に半分ずつ出る。平らな面を最初にクリックしたなら、管の中心はその面と同じ高さにあり、管はその面に半分埋まる。

![描画平面の図。最初にクリックした面を含む平面が固定され、その後の点はすべてその平面へ投影される。管の断面の中心は平面にちょうど乗り、管は平面の両側に半分ずつ出る](images/air-vents-plane.png)

## ⌨️ 描画中のキー

| キー                                               | 動作                                                       |
| -------------------------------------------------- | ---------------------------------------------------------- |
| 左ドラッグ                                         | 線を 1 本描く。ドラッグするたびに別の線（別の管）になる。  |
| **Ctrl** + 左クリック                              | 最後の線の端から、クリックした位置まで直線で延ばす         |
| **S**                                              | 最後の線の角を丸める（両端の位置は保つ）                   |
| **Backspace**                                      | 最後の線を消す                                             |
| **Ctrl+Z** / **Ctrl+Shift+Z**（または **Ctrl+Y**） | 描画中の取り消し / やり直し（macOS では Cmd も使える）     |
| **Enter**                                          | 確定して、対象の型をくり抜く                               |
| **Esc**                                            | 取消。描いた線をすべて捨てて終了する。型は何も変わらない。 |

> ⚠️ **注意**: ヘッダーの表示は `Undo/Redo: Ctrl-Z/Shift-Z` だが、やり直しは **Ctrl+Shift+Z**。Shift+Z だけでは何も起きない。

視点の操作と **N** / **T** は、描画中も使える。

![Draw Air Vents の描画中の画面。ヘッダーに操作キーが表示され、描いた線に沿った管のプレビューが見える](images/air-vents-drawing.png)

### 確定できないとき

曲がりが急で、その直径の管が作れないときは、ヘッダーにメッセージが出て **Enter で確定しない**。

- `Bend too tight: smooth the line or reduce Diameter`: 曲がりが直径に対して急すぎる
- `A vent cannot double back; smooth the bend`: 線が折り返している

**S** で滑らかにする、**Diameter** を小さくする、または **Backspace** で消して描き直す。

## ✅ 確定した後

- 管はすべて 1 つのオブジェクトにまとまる。名前は、対象の型のうち 1 つの名前 + `.Air Vents`（例: `Mold.001.Air Vents`）
- このオブジェクトは **ワイヤー表示でシーンに残る**（レンダーには出ない）。編集・移動すると空気孔も変わる
- 対象の型 **すべて** に、このオブジェクトを使う **Air Vents** Boolean モディファイア（Difference、Exact）が付く
- 追加全体は **Ctrl+Z** 1 回で取り消せる

> ⚠️ **注意**: 管のオブジェクトはシーンに残るので、全選択して Export STL を押すと STL に混ざる。
