# 空気孔（Air Vents）

[README に戻る](../README.md)

## 📝 TL;DR

- 線を描くと、その線に沿った円い管ができる。管は、**選択した型すべて** からくり抜かれる
- 線は型の表面ではなく、**最初のクリックで決まる 1 枚の平面の上** に描く
- 管の断面の中心は、**描画平面にちょうど乗る**
- 急な曲がりで確定できないときは、**S で滑らかにするか、Diameter を小さく** する
- 管のオブジェクトはシーンに残る。**全選択での STL 出力に注意**

## 🧭 概要

線を描いて、その線に沿った円い断面の管を作り、選択した型すべてからくり抜く。

Processing パネルの **Air Vents** の見出しを開いて使う。

![Air Vents の欄。1 が Diameter、2 が Draw Air Vents ボタン](images/air-vents-panel.png)

| 項目                   | 内容                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Diameter**（図の 1） | 管の直径（既定 2 mm）。シーンの長さの単位で表示され、`2 mm` のように単位を付けて入れられる。描画中に変えると、プレビューがその場で太さを変える。 |

## 🛠️ 始める

1. 空気孔を開けたい型を **すべて選択** する（Object Mode）。
2. **Draw Air Vents**（図の 2）を押す。

対象になるのは、描き始めた時点で選択されていたメッシュ。

描画中に選択を変えても、対象は変わらない。メッシュ以外は対象外。

3D ビューを 4 分割表示（Quad View）にしていると始められない。

Draw Surface Cut の描画中も始められない。

## 📐 描画平面の決まり方

Air Vents の線は、型の表面ではなく **1 枚の平面の上** に描く。

- 最初のクリックで、選択した型の面をクリックする。**クリックした点を通り、その面と平行な平面** が描画平面になる。平面はその後は変わらない。
- 型のないところをクリックしても、平面は決まらない。もう一度、型の面をクリックする。
- その後に描く点はすべて、マウスの位置から画面の奥へ伸ばした線が **その平面と交わる点** に置かれる。
- マウスが別の面（曲面など）の上にあっても、その面には沿わない。型の外の何もない所でも、平面上に点が置かれる。
- 平面を真横から見ている（平面が視線とほぼ平行な）ときや、平面が視点より後ろにあるときは、点が追加されない。視点を回す。

管は、断面の **中心が描画平面にちょうど乗る** ように作られる。中心は、平面から上にも下にもずれない。

そのため、管の半分は平面の片側に、残りの半分は反対側に出る。

平らな面を最初にクリックした場合、管の中心はその面と同じ高さにあり、管はその面に半分埋まった形になる。

![描画平面の図。最初にクリックした面を含む平面が固定され、その後の点はすべてその平面へ投影される。管の断面の中心は平面にちょうど乗り、管は平面の両側に半分ずつ出る](images/air-vents-plane.png)

## ⌨️ 描画中のキー

| キー                                               | 動作                                                       |
| -------------------------------------------------- | ---------------------------------------------------------- |
| 左ドラッグ                                         | 線を 1 本描く。ドラッグするたびに別の線（別の管）になる。  |
| **Ctrl** + 左クリック                              | 最後の線の端から、クリックした位置まで直線で延ばす         |
| **S**                                              | 最後の線の角を丸める（両端の位置は保つ）                   |
| **Backspace**                                      | 最後の線を消す                                             |
| **Ctrl+Z** / **Ctrl+Shift+Z**（または **Ctrl+Y**） | 描画中の取り消し / やり直し（macOS では Cmd も使える）     |
| **Enter**                                          | 確定して、対象の型をくり抜く                               |
| **Esc**                                            | 取消。描いた線をすべて捨てて終了する。型は何も変わらない。 |

> ⚠️ **注意**: ヘッダーには `Undo/Redo: Ctrl-Z/Shift-Z` と表示される。
> 実際のやり直しは **Ctrl+Shift+Z**（Ctrl と Shift を押しながら Z）。Shift+Z だけでは何も起きない。

視点の操作と、**N** / **T** によるサイドバー・ツールバーの開閉は、描画中も使える。

サイドバーの Diameter も、描画中に変えられる。

![Draw Air Vents の描画中の画面。ヘッダーに操作キーが表示され、描いた線に沿った管のプレビューが見える](images/air-vents-drawing.png)

### 確定できないとき

線が急に折れ曲がっていて、その直径の管が作れないときは、ヘッダーにメッセージが出て、**Enter を押しても確定しない**。

- `Bend too tight: smooth the line or reduce Diameter`: 曲がりが直径に対して急すぎる
- `A vent cannot double back; smooth the bend`: 線が折り返している

対処は次のどれか。

- **S** で線を滑らかにする
- **Diameter** を小さくする
- **Backspace** で線を消して描き直す

## ✅ 確定した後

- 描いたすべての管は、1 つのオブジェクトにまとめられる。名前は、描き始めたときに選択していた型のうち 1 つの名前に `.Air Vents` を付けたもの（例: `Mold.001.Air Vents`）。
- このオブジェクトは、シーンに **ワイヤー表示で残る**（レンダーには出ない）。
- 描き始めたときに選択していた型 **すべて** に、このオブジェクトを使う **Air Vents** という Boolean モディファイア（Difference、Exact）が付く。
- 管のオブジェクトを編集・移動すると、空気孔もそれに合わせて変わる。
- 空気孔の追加全体は、**Ctrl+Z** で 1 回の操作として取り消せる。

> ⚠️ **注意**: 管のオブジェクトはシーンに残るので、全選択して Export STL を押すと STL に混ざる。
> 出力の前に選択を確認する。
