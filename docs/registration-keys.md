# ダボ（Registration Keys）

[README に戻る](../README.md)

## 📝 TL;DR

- ダボは、分離済みの **2 つの別々のオブジェクト** の間に付ける
- **ピンが突き出す型をアクティブ** にし、**穴が開く型を Socket** に選ぶ
- 穴は、ピンより **片側 Clearance per Side ずつ広く**、**Tip Clearance だけ深く** なる
- **Place Keys** の後は、クリックするたびにダボが増える。終わったら **Done か Esc**

## 🧭 概要

割った型の合わせ面に、位置合わせ用のダボ（凸と凹の組）を付ける。

片方の型に凸（ピン）を足し、もう片方の型に、それより少し大きい凹（穴）を開ける。

Processing パネルの **Registration Keys** の見出しを開いて使う。

![Registration Keys の欄。1 が Socket、2 が Shape、3 が寸法、4 が向き、5 が Place Keys と Done のボタン](images/registration-keys-panel.png)

## 🛠️ 準備

ダボは、**2 つの別々のオブジェクト** の間に付ける。

- 型を [Separate Loose Parts](surface-cut.md#-separate-loose-parts) で分けておく。Surface Cut を付けただけの型は 1 つのオブジェクトなので、そのままではダボを付けられない。
- 2 つの型は、どちらも閉じたメッシュにし、組み合わさった位置に置いておく。

どちらの型をどこで指定するかは、**できあがる形** で決める。

| できあがる形                 | その型の指定のしかた               |
| ---------------------------- | ---------------------------------- |
| ピン（凸）が **突き出す** 型 | クリックして **アクティブ** にする |
| 穴（凹）が **開く** 型       | **Socket**（図の 1）の欄で選ぶ     |

- 欄の一番上の `Active half: pin` は、「アクティブな型 = ピンが付く側」という意味。
- **Socket** は「差し込まれる受け口」の意味で、穴が開く側。Socket に選んだ型に、ピンが付くことはない。

> ⚠️ **注意**: 逆に指定すると、ピンと穴の付く型が入れ替わる。
> アクティブにする型を先に決め、残りの型を Socket に選ぶ。

**Place Keys**（図の 5）は、次の条件をすべて満たすときだけ押せる。

- Object Mode である
- アクティブなオブジェクトがメッシュである
- **Socket** にメッシュが指定されていて、それが **アクティブなオブジェクトとは別** である

## 📐 形と寸法

**Shape**（図の 2）で形を選ぶ。

| Shape                     | 形                                                     |
| ------------------------- | ------------------------------------------------------ |
| **Round Dowel**           | 円柱のピン                                             |
| **Tapered Dowel**（既定） | 先に向かって細くなるピン。はめやすい                   |
| **Rectangular Key**       | 角形のキー。回り止めや、長くして細長い凸と溝として使う |

寸法（図の 3）は、シーンの長さの単位で表示される。`4 mm` のように単位を付けて入れられる。

![ダボの寸法の図。ピンは分割面から Protrusion だけ突き出し、Root Overlap だけ凸側の型に埋まる。穴はピンより片側 Clearance per Side ずつ広く、Tip Clearance だけ深い](images/registration-key-dimensions.png)

| 項目                                | 意味                                                                                                                                           | 既定値     |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| **Width / Diameter**                | ピンの幅（円柱なら直径）                                                                                                                       | 4 mm       |
| **Length**                          | 角形キーの長さ（Rectangular Key のときだけ表示）                                                                                               | 8 mm       |
| **Taper Angle** / **Tip Reduction** | 先細りの角度と、先端での幅の縮小率（Tapered Dowel のときだけ表示）。どちらかを変えると、幅と突出量に合わせてもう片方が変わる。縮小率は最大 90% | 縮小率 0.2 |
| **Protrusion**                      | ピンが分割面から突き出す長さ                                                                                                                   | 3 mm       |
| **Root Overlap**                    | ピンの根元が、凸側の型の中に埋まる長さ。型としっかりつながるようにするため                                                                     | 1 mm       |
| **Clearance per Side**              | 穴とピンのすき間。**片側** の値で、穴の幅はピンの幅より、この値の **2 倍** 大きくなる                                                          | 0.15 mm    |
| **Tip Clearance**                   | ピンの先端と穴の底のすき間。穴の深さは、Protrusion にこの値を足した長さ                                                                        | 0.2 mm     |

例: Round Dowel で、Width / Diameter 5 mm、Clearance per Side 0.1 mm、Protrusion 4 mm、Tip Clearance 0.3 mm とする。

- 穴の直径は 5 + 0.1 × 2 = 5.2 mm
- 穴の深さは 4 + 0.3 = 4.3 mm

### 向き（図の 4）

| 項目                      | 内容                                                                                                                                                                       |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Perpendicular to Face** | オン（既定）: クリックした面に垂直な向きに付ける。オフ: 下に出る **Direction**（ワールドの X / Y / Z）の向きに付ける。曲面上の複数のダボの抜く方向をそろえたいときに使う。 |
| **Flip Direction**        | 向きを反対にする。                                                                                                                                                         |
| **Rotation**              | 面内の回転角（角形キーの向きなど）                                                                                                                                         |

## 📍 ダボを付ける

1. ピンを突き出させたい型をクリックしてアクティブにし、**Socket** には穴を開けたい型を選ぶ。
2. 形と寸法を設定して、**Place Keys** を押す。ツールバーの **Registration Keys** ツールに切り替わる。
3. アクティブな型の表面にマウスを乗せると、カーソルの位置にピン（オレンジ）と穴（青）の輪郭が表示される。付けたい位置でクリックすると、ダボが 1 組追加される。
4. 続けてクリックすると、さらにダボが追加される。
5. 終わったら **Done** を押すか、3D ビューで **Esc** を押す。通常の選択ツールに戻る。

![Registration Keys ツールでアクティブな型の分割面にマウスを乗せたところ。ピンの輪郭がオレンジ、穴の輪郭が青で表示される](images/registration-keys-placing.png)

> 💡 **ヒント**: クリックで拾うのは、**アクティブな型の表面だけ**。
> もう片方の型が手前にあっても、その奥にあるアクティブな型の分割面を狙ってクリックできる。

追加されたダボは、Boolean モディファイア（**Registration Key**、Exact）として付く。

凸側の型には **Union**、凹側の型には **Difference**。

ダボの形のオブジェクト自体は非表示。それぞれの型の子になっているので、型を動かすとダボもついてくる。

置けない位置では、警告が出て何も追加されない。

- `Mold halves must be closed solids`: どちらかの型が閉じたメッシュではない
- `Key must overlap both halves and protrude from the pin half; adjust position or direction`: ダボが両方の型に重なっていない、または凸側から突き出していない（分割面でない場所をクリックした、向きが逆、など）

## 🔧 付けたダボを直す

Registration Keys ツールのままで操作する。

| 操作                                               | 動作                                                                                                |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 既存のダボにマウスを乗せる                         | 緑の輪郭で表示される                                                                                |
| 既存のダボをクリック                               | そのダボを選択し、その設定をパネルに読み込む（Socket も含む）。欄に `Selected: <名前>` が表示される |
| 選択後にパネルの値を変えて **Update Selected Key** | 同じ位置のまま、新しい設定で作り直す                                                                |
| 既存のダボをドラッグ                               | 型の表面に沿って移動する（ドラッグ中の Esc か右クリックで移動を取消）                               |
| **Delete** / **X**、または **Delete Selected Key** | 選択中のダボ（凸と凹の組）を削除する                                                                |

![左は凸側の型に付いたピン（上の型を隠して撮影）。右はダボを選択したときのパネルで、1 が Selected の表示、2 が Update Selected Key、3 が Delete Selected Key](images/registration-keys-selected.png)

追加・移動・更新・削除は、それぞれ 1 回の操作として **Ctrl+Z** で取り消せる。

> ⚠️ **注意**: 曲面での抜く方向や、穴が壁を突き抜けないかは、自動では判定しない。
> 付けた後に形を確認する。
