# 壁と Boolean（Inherit Shape / Solidify / Boolean）

[README に戻る](../README.md)

## 📝 TL;DR

- **Inherit Shape** で、マスターを残したまま同じ形のオブジェクト（`.inherit`）を作る
- **Solidify** で `.inherit` に外向きの壁を付けると、内側の空洞がマスターと同じ形になる
- 壁を付けた直後は `.inherit` が選択されている。**シリコーンの量はマスターを選び直して** 測る
- **Boolean** は **アクティブなオブジェクト** に付く。Operand と同じオブジェクトだとボタンが押せない
- **Inherit Shape で作ったオブジェクトに Apply Solidify は使わない**

## 🧭 使う場所

Processing パネルの **Inherit Shape**、**Solidify**、**Boolean** の見出しを開いて使う。

どれも Object Mode で操作する。

## 🔗 Inherit Shape

マスターそのものには手を加えずに、マスターと同じ形のオブジェクトを作る。

型の壁は、このオブジェクトに付ける。

![Inherit Shape の欄。1 が Inherit Shape ボタン、2 がコレクションの指定欄、3 が Inherit Collection Shape ボタン](images/inherit-shape.png)

1. マスターをクリックしてアクティブにする。
2. **Inherit Shape**（図の 1）を押す。

`<マスター名>.inherit` という新しいオブジェクトが同じ位置にでき、**それだけが選択され、アクティブ** になる。

- 新しいオブジェクトのメッシュ自体は空。**Inherit Shape** という Boolean（Union）モディファイアでマスターを参照しているので、マスターと同じ形に見える。
- マスターは変わらない。後でマスターを編集すると、`.inherit` の形もそれに追従する。
- マスターを消したり移動したりすると、`.inherit` の形も消えたり動いたりする。マスターは残しておく（非表示にしてもよい）。

### コレクションから作る

複数のメッシュを 1 つの形として扱うときは、それらを 1 つのコレクションに入れる。

図の 2 の欄でそのコレクションを選び、**Inherit Collection Shape**（図の 3）を押す。

コレクション内（子コレクションを含む）のすべてのメッシュを Union した形を参照するオブジェクトが、シーンの一番上のコレクションに作られる。

- コレクションには、メッシュ以外のオブジェクトを入れない（エラーになる）。
- シーン直下のコレクション（Scene Collection）そのものは指定できない。

## 🧱 Solidify

選択したメッシュに厚みを付けて、型の壁にする。

![Solidify の欄。1 が Thickness、2 が Flip Direction、3 が Even Thickness、4 が Solidify ボタン、5 が Apply Solidify ボタン](images/solidify.png)

| 項目               | 内容                                                                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Thickness**      | 壁の厚さ。シーンの長さの単位で表示される。`3 mm` のように単位を付けて入れられる（[単位の扱い](units.md)）。                              |
| **Flip Direction** | オフ（既定）: 面の表側（法線の向き）へ厚みを付ける。閉じたメッシュでは外側に壁ができ、内側の形は元の形のまま。オン: 内側へ厚みを付ける。 |
| **Even Thickness** | オン（既定）: 角でも指定した厚さを保つ。                                                                                                 |

**Solidify**（図の 4）を押すと、選択中のすべてのメッシュに **Silicone Casting Solidify** という Solidify モディファイアが付く。

- 設定を変えてもう一度押すと、同じモディファイアが新しい設定に更新される。モディファイアが重ねて増えることはない。
- サイドバーの値は、ボタンを押したときに読み込まれる。値を変えただけでは、付いているモディファイアは変わらない。

できた壁は、外側の面と内側の面の両方を持つ閉じたメッシュ。

マスターの形を参照する `.inherit` に外向きの壁を付けると、内側の空洞がマスターと同じ形になる。

### 型の壁を作る手順

マスターを残したまま壁を作り、シリコーンと樹脂の量を測るまでの流れ。

各手順で、**どのオブジェクトが選択・アクティブになっているか** に注意する。

| 手順 | 操作                                                                            | 操作する時点で選択・アクティブなもの          | 結果                                                        |
| ---- | ------------------------------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------- |
| 1    | **Inherit Shape** を押す                                                        | マスター（クリックしてアクティブにしておく）  | `<マスター名>.inherit` ができ、選択・アクティブがそれに移る |
| 2    | **Thickness** を入れ、**Flip Direction** をオフにして **Solidify** を押す       | `.inherit`（手順 1 で自動的に選択されたまま） | `.inherit` に外向きの壁が付く。マスターは変わらない         |
| 3    | シリコーンの量を測る: マスターをクリックして選び直し、**Measure Volume** を押す | マスター                                      | マスターの体積 = 型の空洞 = 必要なシリコーンの量            |
| 4    | （必要なら）樹脂の量を測る: `.inherit` だけを選び、**Measure Volume** を押す    | `.inherit`                                    | 壁だけの体積 = 印刷する樹脂の量                             |

> ⚠️ **注意**: 手順 2 の後にそのまま Measure Volume を押すと、選択されている `.inherit`（壁）が測られる。
> シリコーンの量を測るときは、必ず手順 3 のようにマスターを選び直す（[何を測るか](measurement.md#%E4%BD%95%E3%82%92%E6%B8%AC%E3%82%8B%E3%81%8B)）。

マスターに直接 Solidify を付けると、マスター自体が壁になる。

その場合、シリコーンの量を測るためのマスターの体積が得られない。

### Apply Solidify

**Apply Solidify**（図の 5）は、選択中のメッシュから **Silicone Casting Solidify だけ** をメッシュに焼き込み、そのモディファイアを外す。

焼き込みはオブジェクト自身のメッシュに対して行い、他のモディファイアの効果は含めない。他のモディファイアはそのまま残る。

> ⚠️ **注意**: **Inherit Shape で作ったオブジェクトには使わない。**
> 自身のメッシュが空なので、焼き込んだ結果も空になり、壁が消えてマスターの形だけに戻る。
> その場合は **Ctrl+Z** で戻す。

形をまとめて確定するときは、[Separate Loose Parts](surface-cut.md#-separate-loose-parts) を使う。すべてのモディファイアを適用したコピーを作る。

ほかのオブジェクトとメッシュを共有しているオブジェクトには、Apply Solidify は使えない（警告が出る）。

## ➖ Boolean

型から注ぎ口の円柱をくり抜く、といった加工に使う。

![Boolean の欄。1 が Operand、2 が Solver、3 が Difference・Union・Intersect のボタン](images/boolean.png)

| 項目                                       | 内容                                                                                                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Operand**                                | 加工に使う **別の** メッシュ（くり抜く形、足す形）。メッシュだけが選べる。                                                                            |
| **Solver**                                 | 計算方法。**Manifold**（閉じたメッシュ向けで最も速い）、**Exact**（既定。重なりや同一平面の形に強い）、**Float**（単純で速いが重なった形に弱い）      |
| **Difference** / **Union** / **Intersect** | 押したボタンの演算の Boolean モディファイアを追加する。Difference はアクティブから Operand を引き、Union は足し、Intersect は重なった部分だけを残す。 |

Boolean モディファイアは、**アクティブなオブジェクト** に付く。

Operand のオブジェクトは変わらない。

1. 加工される型をクリックしてアクティブにする。
2. **Operand** に、くり抜く形などのメッシュを指定する。
3. **Difference** などを押す。押すたびに、モディファイアが 1 つ追加される。

### ボタンが押せないとき

次のどれかに当てはまると、3 つのボタンは灰色になる。

- Object Mode ではない
- アクティブなオブジェクトがメッシュでない、または選択されていない
- **Operand** が空
- **アクティブなオブジェクトと Operand が同じ**

複数のオブジェクトを Shift+クリックで選ぶと、**最後にクリックしたもの** がアクティブになる。

Operand にするオブジェクトを最後にクリックすると、アクティブと Operand が同じになり、ボタンが押せない。

加工される型を最後にクリックする。

![Operand にするオブジェクトを最後にクリックしてアクティブにしてしまい、Boolean のボタンが押せなくなっている状態](images/boolean-disabled.png)

### ⚠️ 注意

- **Operand** の欄は、Surface Cut の欄の一番上にある Operand と **同じ設定**。片方で変えると、もう片方も変わる。
- Operand に使ったオブジェクトは、そのままシーンに残って表示される。邪魔なら非表示にする（非表示にしても Boolean は効く）。
- STL 出力や体積計測のときは、Operand のオブジェクトを選択に含めない。
