# 自由描画による曲面切断

## ユーザーが指定した動作

- 既存エッジの選択ではなく、型の表面に自由に線を描く。
- 平面だけでなく曲面で切断する。
- 1ループを埋める場合と、中空形状の外周・内周の間をつなぐ場合を同じUIで扱う。ループ数のモード切り替えを設けない。
- 切断面の内部はデフォルトで自動補間し、必要なら内部の曲がり方も調整できる。

## 操作

- Processing の `Draw Surface Cut` から開始する。描画先はアクティブメッシュの評価済み形状。
- 左ドラッグで表面に描く。途中で離して視点を回し、線の末尾から再開できる。
- 始点の近くまで戻って C で閉じる。追加のループも同じ操作で描く。
- Space で切断面をプレビューする。Backspace で描画へ戻る／未確定の線を消す／最後のループを開き直す。
- Enter で既存の1本の `Surface Cut` モディファイアを追加する。Esc は一時データだけを破棄する。
- `Edit Cutting Surface` は最新の描画切断面を編集モードで開き、`Cut Interior` グループの内部頂点だけを選択する。境界は `Cut Boundary` グループに保存する。面の編集が切断へ反映される。
- 切断面は別のメッシュとして保存し、元メッシュを維持する。パーツの独立オブジェクト化には既存の分離機能を使う。

## 自動補間の範囲

- 境界から投影面を求め、外周・穴を入れ子関係で判定する。ループの順番・向き・頂点数に依存しない。
- 境界の3D座標を固定し、三角形分割した内部の高さを離散ラプラシアンで滑らかに補間する。
- 自由描画の冗長な点は型の対角長の0.05%以内の誤差で整理する。境界同士を直接つなぐ内部の辺には自由頂点を追加し、表皮に沿った小片が残ることを抑える。
- 一つの外周と、その内側の穴を扱う。投影で交差・接触する線、複数の外周、穴の中の島などは描き直しを求める。深く折り返す面を一般的に解く機能ではない。
- Boolean が型の表皮を貫通できるよう境界外に小さな延長面を追加する。
- 描画は可視の表面へのレイキャストであり、線は描画時点の形状のスナップショット。元の型の変形に線を再投影する処理は行わない。

## 検証

- tier 1: 境界保持、曲面補間、穴の位相、異なる向き・頂点数・変換、不正入力、ソリッド／中空形状の水密な2分割、内部編集のライブ反映。
- `tests/blender/draw_surface_cut.py`: GUIと実イベントによる描画・キャンセル・プレビュー・確定・内部編集。`--enable-event-simulate` 付きの検証用Blenderで実行する。
