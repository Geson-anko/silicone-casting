# 切断面のダボ・噛み合わせ

- Processing の Registration Keys に配置する。分離済みの閉じた型を対象とし、アクティブメッシュが凸側、Socket Half が凹側。両方の型は組み合う位置で使う。
- 円柱、先細り円柱、角形キーの 3 種類。角形は長さを伸ばして舌・溝に使える。
- 幅／直径、角形の長さ、突出量、根元の埋め込み、片側クリアランス、穴底の隙間は `DISTANCE` / `LENGTH` 型で入力する。既存の mm 保存値は互換性のため維持する。先細り率と面内回転も入力可能。
- Place Keys で Blender 標準のワークスペースツールを有効にする。3D カーソルは配置に使わない。マウス位置へ凸／凹の輪郭を表示し、アクティブな型の面をクリックして追加する。
- 既存のダボをクリックすると選択して保存済み設定をパネルへ読み込む。設定変更後 Update Selected Key で適用。ドラッグで元の型の面上を移動。Delete で選択中のペアを削除。Done または Esc で通常の選択ツールへ戻る。
- 面法線への整列を維持した寸法編集では、型の回転に追随したダボの面内方向を保持する。回転角を編集した場合は現在の方向へその差分を反映する。親の拡縮があっても、更新する寸法は入力した実寸とする。
- 面法線への垂直配置が既定。無効時は世界座標の X / Y / Z 軸を選ぶ。反転可能。曲面で共通の脱型方向に揃えたい場合は固定軸を使う。
- 追加・移動・寸法編集・削除は各操作単位で Blender 標準 Undo / Redo に対応する。ドラッグ中の Esc はその移動をキャンセルする。ジェスチャー中は元の型を変更せず、輪郭だけを描く。
- 凸側へ Union、凹側へ Difference の Exact Boolean を追加し、補助メッシュは親の型へ追随する。各ダボの設定・ペア参照・面法線を保存して再編集できる。
- 不正な接触や閉じた正体積を失う Boolean 結果は拒否する。移動・編集失敗時は元の形状へ戻す。
- 貫通穴や局所的な壁厚、曲面での複数キーの脱型方向は自動判定しない。
- 旧カーソル配置の公開オペレータは互換性のため残すが、新しいパネルからは使わない。旧方式で作成した未記録のペアは新ツールによる編集対象に含めない。
