# 切断面のダボ・噛み合わせ

- Processing の Registration Keys に配置する。分離済みの閉じた型を対象とし、アクティブメッシュが凸側、Socket Half が凹側。
- 円柱、先細り円柱、角形キーの 3 種類。角形は長さを伸ばして舌・溝に使える。
- 幅／直径、角形の長さ、突出量、根元の埋め込み、片側クリアランス、穴底の隙間はシーンの距離単位（`DISTANCE` / `LENGTH`）で入力する。既存の mm 保存値は互換性のため維持する。先細り率と面内回転も入力可能。
- 3D カーソルに最も近い評価済み凸側の面へ配置。既定はワールド空間の面法線に垂直。無効化時はカーソルの姿勢を使用。反転可能。
- プレビューボタンで凸と凹の補助メッシュを生成・更新。元の型は変更しない。設定／カーソルの変更後は更新を押す。確定は表示中の形状と記録済みの対象を使う。
- 確定時は凸側に Union、凹側に Difference の Exact Boolean を追加し補助メッシュを非表示にする。繰り返して複数配置可能。元のメッシュには焼き込まない。
- 非接触、突出しない凸、閉じていない型、閉じた正体積を失う Boolean 結果は拒否し、追加したモディファイアを戻してプレビューを残す。
- 貫通穴や局所的な壁厚、曲面での複数キーの脱型方向は自動判定しない。必要に応じて共通のカーソル方向を指定する。
