# STL 出力機能 仕様

- 作成日: 2026-08-28
- ブランチ: `feature/20260828/stl-export`

## 目的

Blender 標準の STL Export 画面で毎回指定していた「Selection Only」「Apply
Modifiers」とミリメートルへの単位換算・ファイル名入力を、サイドバーの 1 操作へまとめる。
既定の単位スケールでは従来どおり 1000 倍とし、単位スケールを変えても印刷実寸を維持する。

## 振る舞い

- Processing セクションに **Export STL** ボタンを置く
- オペレータの公開 ID は `silicone_casting.export_stl` とする
- Object Mode でメッシュが 1 つ以上選択されているときだけ実行できる
- 保存画面の既定ファイル名は、アクティブな選択メッシュのオブジェクト名に
  `.stl` を付けたものとする
  - アクティブオブジェクトが選択メッシュでなければ、選択メッシュの先頭を使う
  - オブジェクト名は加工せず、そのまま既定名に使う
- Blender 起動後の最初の既定保存先は、保存済み `.blend` ならそのディレクトリと
  する。未保存なら Blender が解決する現在の保存先に任せる
- STL 出力が成功したら、その出力フォルダを同じ Blender セッション内だけ記憶し、
  次回の既定保存先にする。記憶先は `WindowManager` のランタイム状態とし、
  `.blend` は変更済みにしない
  - ファイル選択をキャンセルした場合や出力に失敗した場合は更新しない
  - Blender を終了すると記憶は破棄され、次回起動時は `.blend` の保存先へ戻る
- ファイル選択には `WindowManager.fileselect_add()` を使う。これは Blender が
  アドオンへ提供する標準ファイルブラウザーであり、OS ネイティブのダイアログを
  直接呼ぶものではない
- ファイル選択中に選択やモードが変わり得るため、保存確定時にも実行条件を
  再検証する
- 拡張子が省略された場合は `.stl` を付ける

## 固定する STL 設定

`bpy.ops.wm.stl_export` を次の引数で呼ぶ。

| 引数 | 値 |
| --- | --- |
| `export_selected_objects` | `True` |
| `apply_modifiers` | `True` |
| `global_scale` | `1000.0 * scene.unit_settings.scale_length` |
| `use_scene_unit` | `False`（上の式で換算済み） |

`scale_length` は計測・肉厚設定と同じく、単位系が `NONE` の場合も使う。
Blender の `use_scene_unit=True` は単位系 `NONE` ではスケールを無視するため、
アドオン側で換算して二重適用を防ぐ。

モディファイアは出力結果だけに反映し、元オブジェクトへ焼き込まない。それ以外の
STL 設定は Blender 5.1 の既定値を使う。

## 検証

- tier 1 は実 `bpy` の STL exporterでバイナリ STL を一時ディレクトリへ書き、
  未選択オブジェクトが入らないこと、Solidify の厚みが入ること、単位系・スケールを
  変えても 20 mm の立方体が 20 mm で出力されることを検証する。また、出力成功後の次回既定保存先が直前の
  出力フォルダになることを検証する
- tier 2 はビルド・インストール後の実 Blender で同じ不変条件を検証する
- ファイルブラウザーの見た目と操作は背景実行では検証できないため、必要に応じて
  `just dev` で手動確認する
