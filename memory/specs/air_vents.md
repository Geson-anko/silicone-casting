# 空気孔の自由描画

## 要求

2026-09-13 の依頼。Surface Cut の Draw に近い操作で平面上に線を描き、その線に沿う円筒状の空気孔を複数の対象へ Boolean で追加する。

確認済みの選択:

- 最初にクリックした面の位置・法線で描画平面を決める。
- 曲がった線にも沿う、つながった丸い管を作る。

## 公開操作と配置

- Processing 内の Air Vents に、距離型の Diameter と Draw Air Vents を置く。
- silicone_casting.draw_air_vents は Object Mode の選択メッシュ群を対象にする。開始時の対象を固定し、同時に選択された非メッシュは対象外。
- 初回クリックは対象の評価済みメッシュ面から平面を決める。その後は対象の表面形状によらず、同じ無限平面へ入力を投影する。初回の空振りでは平面を決めない。
- 左ドラッグで 1 本ずつ描く。複数の線を同じ平面上に追加できる。Ctrl-click は直前の線を直線で延ばす。
- S は最後の線の角を丸める。線の端点は保持する。
- Ctrl-Z / Ctrl-Shift-Z は描画中の Undo / Redo。Backspace は最後の線を削除。
- 視点回転・ズーム・軸切り替え・サイドバー操作を継続できる。描画平面が視線と平行な間は点を追加しない。
- Enter で確定、Esc で全取消。確定前に対象のモディファイアは変更しない。確定全体は Blender 標準 Undo / Redo の 1 操作。
- Surface Cut と Air Vents の描画は同時に起動しない。先の描画を確定または取消してから次を開始する。

## 形状と保存

- Diameter は DISTANCE / LENGTH。物理寸法を mm で保存し、既定値 2 mm をシーンの単位スケールに合わせて表示する。描画中の変更はプレビューへ反映。
- 線の微小な揺れを直径の 5% 以内で簡略化する。断面は円を近似する 64 角形。各線の両端を閉じ、継ぎ目でも直径を保つ。
- 180 度の折り返しや、太さに対して急すぎて隣り合う断面が折り返す曲がりは確定を拒否する。元の線を表示し、S による平滑化または直径の縮小で修正できる。
- 1 回の描画で共通の切削メッシュを 1 個作る。各対象には Exact / Difference / Self Intersection 有効の Boolean モディファイアを追加する。交差する線も切削できる。
- 元メッシュ・既存モディファイア・選択状態は保持する。切削オブジェクトはワイヤー表示、レンダー非表示で残り、Boolean の入力として編集できる。
- 取消・アドオン無効化では一時オブジェクトとメッシュを削除する。複数対象への追加途中で失敗した場合は追加済みモディファイアを戻す。

## 検証

- tier 1: 直径・体積・閉包性・連結性、曲線と回転した平面、重複点、不正入力時のデータ解放、交差する管、対象ごとの非等方スケール、無関係な対象の保持、単位入力。
- GUI: tests/blender/draw_air_vents.py をイベントシミュレーション付き Blender で実行し、描画から取消・複数対象への確定・Undo / Redo まで確認する。
- Surface Cut の既存 GUI チェックで、共通化したビュー操作の回帰を確認する。
- golden mesh は追加・更新しない。形状は解析的な寸法・体積と閉包性で検証する。
