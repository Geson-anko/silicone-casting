シリコーン造形（シリコーンを流し込んで成形する）ために使う **樹脂型を Blender 上で生成し、3D プリンターで印刷できる形にする** アドオンを作る。「樹脂型」はレジン（光造形）に限らず、PLA などの FDM プリントを含むプラスチック製の型全般を指す（2026-09-30 にユーザーが訂正）。マスターモデルから、注型・脱型できる分割型を作るまでのツール群が最終ゴール。

**Why:** ユーザーは実際にシリコーン造形を行っており、型の設計を手作業で毎回やるコストを下げたい。既に個人用プロトタイプを 2 本書いている（[[project_prototype_addons]]）が、品質管理も配布性もない状態だった。

**How to apply:** 機能の良し悪しは「3D プリントして実際に注型できるか」で判断する。「樹脂＝resin」と訳して光造形前提で考えない。FDM スライサー（面の向き・水密性に敏感）での扱い、ノズル径や積層に起因する最小壁厚・クリアランスも前提に含める。watertight であること、抜き勾配があること、型が分割・脱型できることが、コードの綺麗さより優先する。

2026-08-14 に空リポジトリからスケルトン（現在の `CLAUDE.md` / Claude agents / skills / memory / ツーリング / CI / Extension 足場 / 最小オペレータ）を構築。造形機能の本体はこれから、`/agent-team` フローに載せて実装する。
